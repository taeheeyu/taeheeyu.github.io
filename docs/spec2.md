## 2. 주요 기능 및 페이지 구조 (Page Architecture)

웹사이트는 크게 **[메인 홈 화면]**과 **[학생별 상세 소개 페이지 / 모달]**로 구성됩니다.

### 2.1 메인 홈 화면 (`index.html`)
- **타이틀/헤더**: `"우리 반을 소개합니다"`
- **네비게이션/섹션 구획**:
  1. **교육 내용 섹션**
     - **주요 과목/활동**: 제과제빵, 컴퓨터 자격증(ITQ), 이미지 메이킹, 핸드벨 교육 등
     - **세부 항목 표출**: 장소, 일정, 교육 효과, 학생 반응 등 (카드 형태 또는 아코디언 형태)
     - **미래 확장성**: 추후 활동 사진 갤러리/슬라이더를 추가할 수 있도록 깔끔한 UI 래퍼 구조 구현
  2. **학생 소개 섹션**
     - 6명 학생(김정림, 김하음, 정세헌, 임하나, 김성윤, 최예환)의 프로필 카드/그리드 배치 (클릭 시 해당 학생 상세 페이지 또는 뷰로 이동)
  3. **주요 이슈 섹션**
     - 학급 소식, 게시판 카드, 주요 공지사항/이벤트 등을 깔끔한 리스트/카드 형태로 배치

---

### 2.2 학생별 상세 소개 페이지 (`student.html` 또는 동적 렌더링)
> 6명의 학생별 자기소개 화면은 포스트잇/손그림 감성을 살린 특수 레이아웃을 구현합니다.

- **중앙 배치 (Center Area)**:
  - `center student` (학생 얼굴/캐릭터 이미지)와 `center name` (학생 이름 이미지)을 화면 중앙에 세로로 정렬
- **좌우 포스트잇 배치 (Drawing Cards Area)**:
  - 학생이 직접 그린 손그림(`drawing 1.png`~`drawing 6.png`)을 중앙 이미지 좌우에 감성적인 포스트잇(Post-it) 형태로 배치
  - **포스트잇 디자인 규칙**:
    - 자연스러운 회전 각도 적용 (`transform: rotate(-3deg)`, `rotate(4deg)` 등)
    - 그림자 효과 (`box-shadow`)와 마우스 호버 시 약간 확대/수평 정렬되는 애니메이션 효과
    - **중요**: 그림 이미지에 '첫 번째 그림', '두 번째 그림' 등의 텍스트 라벨을 절대 띄우지 않고, **그림 이미지 자체만 표출**
  - **스크롤 방지 (Desktop)**: 데스크톱 화면 기준 한 눈에 들어오도록 이미지 크기 및 간격 반응형 자동 조절 (`overflow: hidden` 또는 뷰포트 내 핏)
  - **모바일 반응형 (Mobile)**:
    - 모바일 화면에서는 중앙 프로필이 상단에 위치하고, 그 아래로 손그림 포스트잇 카드들이 자연스럽고 순차적으로 1열/2열 배치되도록 반응형 CSS 적용
- **그림 클릭 시 상세 모달 (Drawing Detail Modal)**:
  - 손그림(drawing) 포스트잇 클릭 시 팝업/모달창 오픈
  - **모달 내부 내용**:
    - 해당 손그림 확대 이미지
    - **그림을 그리게 된 동기** (Motivation)
    - **그림 관련 이야기 / 설명** (Story & Description)

## 5. 비주얼 스타일 & UI/UX 가이드라인

1. **디자인 톤앤매너**: 따뜻하고 아기자기한 학급 분위기, 포스트잇/손그림 감성의 웹 디자인
2. **컬러 팔레트**: 파스텔 톤 옐로우/크림 바탕, 부드러운 그린/파랑 포인트 컬러
3. **폰트**: 나눔손글씨, Gaegu, Noto Sans KR 등 아기자기한 손글씨 폰트 적용
4. **반응형 최적화**: 데스크톱, 태블릿, 모바일 화면 크기에 적응하는 CSS Flex/Grid 사용

## 6. 개발 실행 단계 명세 (Task Checklist for AI)

1. **[1단계] HTML 구조 및 데이터 파일 생성**
   - `index.html` (메인 화면) 및 `student.html` (학생 소개 템플릿) 구상
   - `js/data.js` 데이터 구조 정의 및 학생 6명(김정림, 김하음, 정세헌, 임하나, 김성윤, 최예환) 기본 더미 데이터 작성
2. **[2단계] CSS 스타일링 (`css/style.css`)**
   - 홈 화면 (교육 내용, 학생 카드, 주요 이슈) 스타일 구현
   - 학생 소개 페이지 (중앙 프로필 + 포스트잇 손그림 회전배치 + 호버 애니메이션) 구현
   - 팝업/모달창 스타일 구현
3. **[3단계] JavaScript 인터랙션 (`js/main.js`)**
   - 6명 학생 카드 클릭 시 동적 이동/렌더링
   - 손그림 포스트잇 클릭 시 동기/이야기 모달창 표출 기능 구현
   - 모바일 네비게이션 및 반응형 조절 기능 구현
4. **[4단계] 검증**
   - 스크롤 불필요 뷰포트 배치 검증, 모바일 화면 레이아웃 깨짐 여부 확인
